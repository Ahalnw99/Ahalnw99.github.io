Crisis Coin (CRS) — สร้างเหรียญด้วยกระเป๋า Phantom ของคุณเอง

DEVNET

หน้านี้ไม่เก็บและไม่ขอ seed phrase / private key ใด ๆ ทั้งสิ้น — ถ้าเห็นหน้าไหนขอ seed phrase ให้ปิดทันที.
ไม่มีค่าบริการให้ใคร: จ่ายแค่ค่าเช่าบัญชี Solana + ค่าธรรมเนียมเครือข่าย + ค่า Metaplex 0.01 SOL.
CRS ไม่ใช่การลงทุน ไม่มีการเสนอขาย ไม่รับประกันมูลค่าหรือกำไร.

MAINNET ใช้ SOL จริงและสร้างเหรียญจริงแบบถาวร ทำเฉพาะเมื่อบอสสั่งเปิดตัวจริงแล้ว และ metadata URI ถูกโฮสต์ถาวรแล้ว

บน devnet ให้เปิด Phantom → Settings → Developer Settings → Testnet Mode → Solana Devnet
Devnet ใช้ placeholder ได้. Mainnet ต้องเป็นลิงก์ถาวร (ar:// หรือ https://) ที่มี name/symbol ตรงกันและมี image. ข้อดี: ไม่มีใครเปลี่ยนชื่อ/โลโก้/ลิงก์ได้อีก (คนตรวจเหรียญชอบ). ข้อเสีย: ถ้าลิงก์โลโก้เสียหรือพิมพ์ผิด จะแก้ไม่ได้ตลอดไป — ใช้กับลิงก์ถาวรเท่านั้น.
